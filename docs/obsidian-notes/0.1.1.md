askMyu 0.1.1 (open beta)

Changes asked for by Obsidian's plugin review, plus a few things it made us look at.

Changed
- The plugin's code now ships readable rather than compressed, so Obsidian's review tools can check it.
- Release files are now signed with GitHub's build attestations.
- The README says which links open in your browser, that the plugin lists your vault's file names to find its own pages, when it uses the clipboard, and where base64 encoding is used.

Fixed
- Smaller fixes to typing and wording throughout, with nothing visible except the terms wording on the sign-up screen, now in plain sentence case.
