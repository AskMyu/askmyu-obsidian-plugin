askMyu 0.0.247 (beta)

Install with BRAT: AskMyu/askmyu-obsidian-plugin

The last test release before 0.1.0 goes to Obsidian's community plugins. Same code as 0.1.0 will be.

New
- Signing in on a device that isn't approved yet now shows that in the Myu pane, with a button to get the device approved. The 4-digit code stays in the pane while you go approve it from your phone or the web app, and the vault unlocks on its own when you do.

Fixed
- Closing the approval dialog no longer cancels the approval. If you switched to the browser to sign in or approve, coming back to Obsidian now picks up where you left off.
- The pane no longer says "Locked" for a device that simply hasn't been approved.

Changed
- The plugin is now called askMyu everywhere: in the plugin browser, in Settings, and in the command palette.
- The askMyu mark shows at the top of Settings again.
- The "Send feedback to AskMyu" command is now just "Send feedback".
