askMyu 0.1.2 (open beta)

Changes asked for by Obsidian's plugin review.

Changed
- Requires Obsidian 1.13 or newer. The plugin now uses Obsidian's current settings and button APIs, which the review asks for.
- Releases are built so that anyone rebuilding the tagged source gets the same file, byte for byte. Obsidian's build check can now confirm the release matches its source.
- Destructive buttons use Obsidian's current styling call. They look the same.

Fixed
- Smaller typing and promise-handling fixes throughout, with nothing visible.
