askMyu 0.1.0 (open beta)

The first release for Obsidian's community plugin browser. If you installed with BRAT, nothing changes: updates keep arriving.

This is the same plugin as 0.0.249, with the version number that marks it ready for the plugin browser.

Since 0.0.246
- Signing in on a device that isn't approved yet shows that in the Myu pane, with a button to get the device approved, and tells you why when it can't go ahead.
- Syncing paces itself and backs off when askMyu asks it to. The Today pane loads in one request, and opening the vault asks only for what changed.
- The plugin is called askMyu everywhere, its mark shows at the top of Settings, and the feedback command is just "Send feedback".
