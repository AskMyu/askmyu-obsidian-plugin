askMyu 0.0.249 (beta)

Install with BRAT: AskMyu/askmyu-obsidian-plugin

Fixed
- The plugin sent far too many requests during a vault sync, enough to get an account's whole connection blocked for a while. Syncing now paces itself, the Today pane refreshes once instead of hundreds of times, and the plugin backs off when askMyu asks it to.
- Progress during a sync updates in place instead of reloading the pane each step.

Changed
- Faster syncs. Opening the vault now asks askMyu what changed since last time instead of re-reading every person and company.
- The Today pane loads in one request instead of six.
